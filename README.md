# Menu App 🍽️

A modern, responsive restaurant menu application built with React and Vite. It features a clean user interface, categorized menu items, and a live deployment.

## 🔗 Live Demo
Check out the live application here: [Menu App](https://menu-app-three-ecru.vercel.app)

## 🛠 Tech Stack
*   **Framework:** React
*   **Build Tool:** Vite
*   **Styling:** Tailwind CSS

## ✨ Features
*   Responsive design for all screen sizes.
*   Categorized menu (Main dishes, Appetizers, Drinks, etc.).
*   Modern and clean UI.
